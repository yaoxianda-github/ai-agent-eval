# 产品信息：智能代码审查助手 CodeReview AI

## 产品定位
面向研发团队的 AI 驱动代码审查工具，集成到 Git 工作流中，自动分析 PR 代码质量、安全漏洞和潜在 bug。

## 核心功能
1. **智能代码审查**：基于大模型分析代码逻辑，识别潜在 bug、边界条件遗漏、错误处理不当等问题
2. **安全漏洞检测**：自动识别 SQL 注入、XSS、硬编码密钥、不安全的加密算法等常见安全问题
3. **代码规范检查**：支持自定义编码规范，检查命名规范、注释完整性、代码复杂度、重复代码等
4. **性能优化建议**：识别性能瓶颈，如 N+1 查询、内存泄漏、不必要的循环嵌套等
5. **CI/CD 集成**：无缝集成 GitHub/GitLab/Gitee，PR 创建时自动触发审查，评论直接显示在代码行上

## 技术优势
- 支持 20+ 编程语言（Python、Java、Go、JavaScript、TypeScript、C++、Rust 等）
- 基于自研代码大模型，代码理解准确率 95%+
- 平均审查时间 < 30 秒，不影响开发节奏
- 支持私有化部署，代码不出企业内网
- 可自定义审查规则和严重级别

## 目标用户
- 中大型研发团队（20人以上）
- 对代码质量和安全有高要求的企业
- 需要规范化代码审查流程的技术团队
