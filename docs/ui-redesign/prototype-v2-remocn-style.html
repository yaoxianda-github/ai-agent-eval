// How it works

三步，从空文件夹到评测报告

不需要学习复杂的评测框架，不需要手动编写测试用例。描述你要测什么，系统帮你完成剩下的。

01
~/agent-eval › agent-eval workbench

打开工作台

一条命令启动 Web 评测工作台，所有操作在浏览器中完成，无需编写代码。

02
tasks/ › select 37 tasks

选择任务与 Agent

从 4 层数据集（黄金/边界/回归/随机）中选择任务，配置待测 Agent，设置重复次数。

03
results/ › report.html

获取报告

确定性校验点自动判定，5 维度置信度评估，6 指标质量门禁，JUnit + Allure 双格式输出。

其他方式都有代价

手动测试

每次升级花 2 天人工回归，覆盖不到 20% 场景，结果不可复现，问题发现全靠运气。

通用评测框架

学习曲线陡峭，需要编写大量测试代码，缺少 Agent 专用的校验点和置信度评估。

只看人工评分

主观偏差大，无法接入 CI 自动阻断，每次评分成本高，无法规模化运行。
