## 4. 配色方案评估（默认 + A–F 共 7 套）

切换入口在 `#/settings`「外观主题」，点击即生效（写入 `data-theme`，localStorage 持久化），全站 token 联动、切换无闪烁，一致性良好。

### 4.1 对比度实测（正文色 / 背景，WCAG）

| 方案 | 主文字/背景 | 次文字/背景 | **弱文字/背景(--text-muted)** | 结论 |
|---|---|---|---|---|
| 默认（黑白灰） | 19.80 ✅ | 5.74 ✅ | **2.85 ❌** | 主/次达标，弱文字不达标 |
| A 暖米棕 | 12.88 ✅ | 5.95 ✅ | **2.98 ❌** | 同上 |
| B 墨绿米白 | 11.46 ✅ | 6.47 ✅ | **3.34 ❌** | 弱文字临界偏弱 |
| C 藏蓝浅灰 | 10.72 ✅ | 7.06 ✅ | **2.39 ❌（最差）** | 弱文字最差 |
| D 炭黑暖灰 | 14.05 ✅ | 7.23 ✅ | **2.43 ❌** | 弱文字差 |
| E 深青浅青 | 11.01 ✅ | 5.50 ✅ | **2.88 ❌** | 次文字刚过线 |
| F 科技浅蓝 | 15.03 ✅ | 8.31 ✅ | **3.28 ❌** | 整体最均衡 |

**结论**：主文字全部 AAA(≥7)、次文字基本 AA；**系统性问题是 `--text-muted` 在 7 套主题里全部不满足 WCAG AA(4.5)**，集中体现在 label、面包屑、顶栏路径、KPI 副标——这是全站最该优先修的可访问性问题。

### 4.2 主题间语义撞色（P1）

`style.css` 中 success/warning/danger 固定不变，但各主题 `--accent` 与语义色撞车：

- **A 暖米棕**：`--accent:#D97706` 与 `--warning:#D97706` **完全同色**，主强调=告警。
- **B 墨绿米白**：`--accent:#2D6A4F` 与 `--info:#2D6A4F` 同色。
- **D 炭黑暖灰**：`--accent:#B45309` 与 `--warning:#B45309` 同色。
- **E 深青浅青**：`--accent:#0D9488` 与 `--info:#0D9488` 同色。

后果：在这些主题下，“主操作/选中态”与“告警/信息”无法区分，削弱状态语义。建议 accent 与 info/warning 拉开明度差。

### 4.3 可辨识度与切换一致性

- 7 套色相互区分度足够（米/绿/蓝/灰/青/科技蓝），缩略卡预览能反映主色；切换即时、全站一致、刷新保留。
- 主题 A 实测截图见 `16-theme-A-warm.png`：暖色背景+橙棕 active 导航协调，但 KPI 大数字深棕在米底上清晰。
- 小问题：选中态仅靠粗边框（S-2）；缩略卡未展示 success/danger 等语义色样本，用户无法预览告警色效果。

## 5. 整体视觉一致性评价

- **风格统一度**：底色 + 1px 细边框 + 10px 圆角 + 等宽数字（JetBrains Mono）的“极简仪表盘”语言贯穿全站，方向正确、统一度中上。
- **拉低完成度的因素**：① emoji 与原生控件（下拉/多选 listbox）混入，破坏精致感；② 中英混排与小写英文状态；③ 色彩语义随意（失败桶蓝紫、error 时长标绿、accent 与 warning 撞色）；④ 内联彩色统计数字过多。
- **信息层级**：H1 大标题（26px/800）+ 面包屑结构清晰，但面包屑与 H1 重复（G-1）；KPI 大数字层级好。
- **视觉噪音**：Badcase 列表 9 个内联彩色数字、监控页竖排小标签、各处彩色 badge 叠加，信息密度偏高。
- **可访问性**：主文字对比度优秀，弱文字系统性不达标；键盘 focus 有（按钮 `:focus` 光晕），但可点击行无 affordance、icon-only 侧栏无 tooltip。
