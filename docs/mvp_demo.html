快速上手

# 安装  pip install -e ".[dev]"
# 可选  pip install -e ".[aider]" （接入第三方 aider 后端）
# API Key（DeepSeek）  setx DEEPSEEK_API_KEY "sk-..."
agent-eval list-tasks                    # 列出任务包
agent-eval run --task T001 --agent minimal-react   # 跑单任务（自研基线）
agent-eval run --task T001 --agent aider           # 跑单任务（第三方）
agent-eval run --task T102 --agent minimal-react --timeout 120
agent-eval report                                 # 生成对比报告
三命令：list-tasks / run / report。轨迹、判定、评分全部落盘到 results/runs/<run_id>/run.json，可下钻到原始证据。
