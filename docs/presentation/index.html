项目概述

AI Agent 评测平台是一套面向大模型 Agent 的自动化质量评测系统，解决了 Agent 能力"无法量化、难以对比、风险不可控"的核心痛点。 平台覆盖结果、过程、效率、风险四层评测体系，支持多 Agent 横向对比、CI/CD 质量门禁、Badcase 智能分析， 已接入 10+ 主流 Agent 后端（Claude Code、DeepSeek、Hermes、Kimi、Trae、Codex 等），累计完成 280+ 次评测运行。

核心功能矩阵

四维质量评测

结果层（任务通过率）+ 过程层（轨迹效率）+ 效率层（响应速度）+ 风险层（安全合规），全面衡量 Agent 能力。

多 Agent 对比矩阵

支持 10+ Agent 后端横向对比，一键发起批量评测，自动生成彩色得分矩阵，快速定位能力差异。

CI/CD 质量门禁

集成 GitHub Actions，核心任务包通过率不达标自动阻断合并，将 Agent 质量纳入工程化流水线。

Badcase 智能分析

自动归因 6 类失败原因（数据逻辑/技能路由/工具参数/输出契约/环境/模型语义），支持一键转化为回归测试用例。

成本核算体系

实时预估每次评测的 LLM 成本，运行后自动结算实际花费，支持按 Agent、任务、时间段多维度成本分析。

指标解释链

建立"模型能力 → 任务完成 → 业务影响"三层指标因果关系，识别"局部指标高但整体完成率低"的虚假繁荣。

风险层安全检测

敏感信息泄露检测、路径越权检测、幻觉工具检测三类安全校验，一票否决机制确保 Agent 上线安全。

CLI 开放能力

提供完整的命令行工具，支持无头模式运行、JUnit XML 报告输出，方便嵌入各类自动化流程。

技术架构

四层评测体系架构图

前端

原生 JS + ECharts 数据可视化，SPA 单页应用，支持多主题切换，响应式适配。

后端

Python FastAPI + SQLite，轻量级架构，支持异步并发执行，易于部署扩展。

执行层

统一 Agent 后端接口协议，已接入 10+ 主流 Agent，插件化架构便于扩展新后端。

判定层

确定性规则校验 + LLM Judge 双重判定，支持 15+ 种 checkpoint 类型。
